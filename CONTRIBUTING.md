# CONTRIBUIÇÃO - ᴘᴛ

Obrigado por considerar contribuir com o projeto. Este projeto foi desenvolvido com foco em aprendizado, experimentação e evolução contínua. Toda contribuição é bem-vinda, seja para corrigir bugs, melhorar a documentação, otimizar o código, aumentar a acessibilidade ou implementar novas funcionalidades.

## Diretrizes

- Mantenha o padrão de código utilizado no projeto
- Escreva código limpo, legível e bem organizado
- Evite alterações não relacionadas ao objetivo do Pull Request
- Sempre que possível, documente novas funcionalidades
- Respeite a arquitetura existente antes de propor mudanças estruturais
- Caso encontre um bug, verifique se ele já não foi reportado antes de abrir uma issue

# CONTRIBUTION - ᴇɴ

Thank you for considering contributing to the project. This project was developed with a focus on learning, experimentation, and continuous evolution. All contributions are welcome, whether to fix bugs, improve documentation, optimize code, enhance accessibility, or implement new features.

## Guidelines

- Follow the project's coding standards
- Write clean, readable, and well-organized code
- Avoid changes unrelated to the Pull Request's objective
- Document new features whenever possible
- Respect the existing architecture before proposing structural changes
- If you encounter a bug, check if it has already been reported before opening an issue
